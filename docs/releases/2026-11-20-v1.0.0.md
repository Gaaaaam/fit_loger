# Fit Loger v1.0.0

发布日期：2026-11-20

版本号：`1.0.0 (1000000)`

## 版本定位

这是 AI 教练转型前的功能基线版本。当前版本专注于离线训练记录、动作指导、有氧器械记录、数据导出和训练趋势，为后续个性化训练方案提供稳定的数据基础。

## 本版内容

- 日历、训练日详情、按部位和按动作录入。
- 组状态、热身、训练技术、RIR、备注、上次训练提示和复制上次训练。
- 125 个内置动作、自定义动作、动作指导图和 3D 肌群选择。
- 跑步机、爬楼机、椭圆机、固定单车和划船机的分段记录。
- 训练容量、关注动作、e1RM、重量与次数、个人纪录、体重和有氧趋势。
- JSON/CSV 导出与 JSON 导入，数据库 schema v4 迁移和迁移前备份。
- 浅色与暗色主题。

## 自动化验证

以下项目校验全部通过：

- 17 项 Node.js 逻辑、数据库、趋势、有氧和资源校验。
- 2 项 Python 人体模型映射与资产校验。
- 动作目录共 125 条，人体模型覆盖 18 个肌群区域。
- 有氧数据的 v4 迁移、JSON/CSV 导出、持久化和趋势统计通过。

此前的指导图、有氧器械和真机安装记录见 [图片与有氧器械整合记录](2026-10-23-artwork-cardio.md)。

## 后续方向

下一阶段将以本版本为稳定基线，增加用户画像、训练约束、AI 周度复盘、可确认的计划草案和基于实际反馈的计划调整。AI 功能不属于 v1.0.0 的发布范围。
