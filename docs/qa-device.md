## 步骤

### 录入与选择器（原 8 条）

1. 新增组，连续输入重量 `12.5`、次数 `10`：键盘不因首位输入自动收起，圆圈保持未完成。离开页面后回来，数值和状态保留。
2. 手动勾选，再修改重量：仍为完成；取消勾选并重新进入页面：保持未完成。
3. 只剩最后一个未完成组时输入、勾选和取消：页面不跳动，输入框不被重建。
4. 添加至少五个动作，每个三组；编辑最下方动作后向上滚动，在中间动作添加组：不跳回旧输入位置。分别在同一部位和不同部位重复。
5. 滚动到页面中间打开动作选择器，新增动作或取消：不强制滚到部位末尾或旧输入框。
6. 打开标签面板，检查两行两列按钮、当前选中高亮、四种标签持久化，切换标签不自动勾选。
7. 在小屏、大字体和深色模式检查九张部位卡片：两列显示，可滚动到有氧；文字与点击区域正常。
8. 使用已有数据库升级，检查原训练记录不变，腹部、核心、有氧均可选择并添加动作，重启不会重复添加内置动作。

### 空状态与换机

9. 新装或清空当月无打点：日历显示「点日期或记录今天开始」。空日显示「这一天还没有训练记录」。
10. 趋势在尚无正式完成组时显示「完成几组正式训练后，这里会显示趋势」。
11. 「我的」导出 JSON+CSV。把 JSON 导入到另一台机或先备份再导入：组数、重量、完成状态一致。
12. 导入任意非本应用 JSON 或损坏文件：提示「导入失败，请选择本应用导出的 JSON 文件」，现有训练还在。

### 3D 与启动

13. 人体模型可旋转、缩放，点肌肉中间即可选中肌群并添加动作。正面能点到胸、肩前束、肩中束、腹直、股四；侧面肩中束点肌肉中部应是三角肌，不是肱二头或肱三头。背面能点到背阔、上背、竖脊、臀、腘绳、小腿。点空头部不选中，提示「没有点到肌群，试试靠近一些，或用肌群列表」。手掌和脚面可能落到邻近肢体肌群，这是已知取舍，不算本条失败。强调色与主界面绿色按钮一致，不是另一套青绿。
14. 模型加载失败（可关资源或弱设备上观察）：出现失败说明，重试或「选择肌群」仍能添加动作。
15. 启动失败页：若无法人为让数据库初始化失败，本条标 N/A 并写原因。能造失败时必须看到「数据未能打开」，不得进入空白主页；重试成功后进入日历。

### 机型

16. 至少 2 款不同尺寸真机各跑一遍上面条目。建议一款常规屏、一款较大屏；系统版本写在结果表。

3D 选肌的代码侧收口已完成（解剖映射、包围盒点选、肩部对准盒子中心、点空提示、资产门禁、强调色）。第 13、14 条仍须在两款真机填写；未填不算这批作业收尾。
