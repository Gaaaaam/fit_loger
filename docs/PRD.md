## 目标用户

在华为手机上练力量训练的人：要在健身房里快速记下动作、组数、重量和次数；数据必须能换机带走，不能锁在云账号里。

## 一句话价值

离线把训练记得又快又准，历史可导出，趋势能看见有没有变强。

## 核心功能与验收

1. **日历进入日详情并勾选完成**
   - 从月历点某一天，或点「记录今天」，进入该日详情。
   - 添加动作与组后，输入重量/次数只保存，**不会**自动标成完成；勾选圆圈才记 `done`。
   - 日历只为有 `done` 组的日期打「已训练」点。
   - 空状态：当月没有任何打点时，显示「点日期或记录今天开始」。空日显示「这一天还没有训练记录」，并提供添加动作 / 复制上次训练。

2. **动作库、自建动作、3D 选肌**
   - 可按部位选内置动作，可搜索，可自建（名称、部位、器械）。
   - 可在人体模型上点选肌群，勾选推荐动作后批量加入当日。
   - 模型加载失败时显示失败说明，可重试或改用肌群列表。

3. **复制上次与继承上一组**
   - 新组预填上一组重量次数；该动作当天第一组则预填上次训练的正式组。
   - 空日可「复制上次训练」，克隆结构且组状态为未完成。

4. **导出与导入（换机）**
   - 「我的」可导出 JSON（完整）和 CSV（扁平）。
   - 可用本应用导出的 JSON 导入；坏文件或非本格式时提示「导入失败，请选择本应用导出的 JSON 文件」，不静默清空现有数据。

5. **趋势：关注动作与本周容量**
   - 趋势页展示关注动作、本周目标/容量、个人纪录、体重。
   - 尚无完成的正式训练记录时显示「完成训练记录后，这里会显示趋势」。
   - 无体重时显示「还没有体重记录」。

6. **有氧器械与基础趋势**
   - 新增跑步机、连续台阶式爬楼机、椭圆机、固定单车、划船机；原四个按次数记录的有氧动作保留原有含义。
   - 一次训练可分多段；默认录入分钟、秒与适用距离，完成时必须有正时长。详细器械指标、心率与面板热量选填，支持热身和备注。
   - 空白训练段可保存为计划；输入不自动完成。新段只继承器械设置，复制训练保留时长／距离目标并清空实际心率、热量、频率和功率。
   - 沿用关注列表展示时长趋势，以及距离或爬楼台阶数。只汇总完成且非热身的有效训练段；计入训练天数，排除力量容量、力量纪录和力量组数目标。
   - 动作卡片与详情使用原创男女双版本 3D 指导图，支持现有模特偏好，图片离线可用。
   - 数据库与 JSON 为 v4，新增指标独立存储，旧版备份兼容；CSV 追加指标列。

## 数据与隐私

v1 无账号、无云端、不采集使用数据。训练记录只存在本机 SQLite。换机靠用户主动导出/导入。完整隐私政策留到上架阶段。

## 空状态文案（必须可见）

| 场景 | 文案 |
| --- | --- |
| 日历当月无打点 | 点日期或记录今天开始 |
| 空的一天 | 这一天还没有训练记录 |
| 趋势无完成记录 | 完成训练记录后，这里会显示趋势 |
| 导入失败 | 导入失败，请选择本应用导出的 JSON 文件 |

不另做引导动画或强制教程。

## 冰柜（真机清单勾完前不准做）

账号与云同步、iOS/Android、LLM、自动配重建议、停滞检测、组间休息计时 UI、社交与训练计划模板。有氧器械按时长／距离记录已于 2026-10-23 由用户确认纳入本轮；设备直连、额外器械变体和有氧专属纪录仍不在本轮范围。
